# VerityGrid illustrative dashboard gallery

This directory contains twelve **illustrative UI concept panels** for the repository README. They are vector SVG artwork, not screenshots of a deployed application. All displayed metrics, names and records are fictional sample content and are explicitly labeled as illustrative, not live data.

The illustrations communicate the product's planned information architecture and dashboard themes. They must not be represented as proof of a working feature, real customer activity, production telemetry or a deployed interface.

To update the gallery, edit the SVG source files directly and preserve the visible “ILLUSTRATIVE • NOT LIVE DATA” disclosure in each panel.
